# Практика Solana на лекции

Источник: https://github.com/0xnurda/solana-practice
Выполнено 12.10.2026 в Devnet. Перевод 0.01 SOL с memo, mint 10000, три перевода по 100 и burn 50 подтверждены. Балансы: 9650 у отправителя, по 100 у трёх собственных тестовых получателей; supply 9950. Собственные получатели использованы с разрешения преподавателя, подтверждённого пользователем.

Задачи по исходному коду:
- dev: перевод 0.01 Devnet SOL с memo Hello Solana на случайный публичный адрес.
- mint: выпуск 10000 SPL-токенов с decimals 6, отправка 3 однокурсникам по 100, burn 50.
- После mint: баланс отправителя 9650, supply 9950.

Исправления: удалён вывод приватного ключа; Devnet проверяется по genesis hash; адреса и кошелёк валидируются до mint; ошибки не раскрывают ключи. Название MYCOIN используется в сообщениях, on-chain metadata исходный код не создаёт.

Запуск в Ubuntu:

```bash
npm ci
npx tsc --noEmit
# WALLET_PATH: отдельный Devnet JSON-кошелёк вне репозитория.
# Или ENV_FILE: путь к приватной конфигурации вне репозитория.
# RECIPIENT_1, RECIPIENT_2, RECIPIENT_3: три публичных адреса однокурсников.
npm run dev
npm run mint
```

Не использовать локальные ключи W6 для Devnet. Не размещать SECRET_KEY, JSON-ключи и seed-фразы внутри проекта. Не запускать mint повторно без проверки результата предыдущего запуска.

Подтверждения: transfer-result.txt, mint-result.txt, balances.json. Все операции завершены; повторный запуск создаст новый токен и повторит операции.
